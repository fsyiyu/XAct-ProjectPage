Abstract 简介

X-Act 将动作迁移（Action Transfer）拆成「动作追踪 → 场景运动规划 → 目标视频生成」三步，全部在一个视频扩散 Transformer（Video Diffusion Transformer）中完成。

动作迁移要保留的是动作语义（Action Semantics）：轨迹、接触时机、物体响应； 必须丢掉的是源视频的外观：手形、皮肤、场景纹理。现有方法要么让与外观纠缠的运动特征直接注入生成，造成严重的身份泄漏（Identity Leakage）； 要么依赖逐帧掩码、轨迹等稠密标注做刚性约束，难以适配新身体结构。两条路线都缺少一个先“看懂动作、再规划动作”的中间推理环节。

X-Act 把参考视频编码成干净的 Trace 段；在去噪过程中预测一段稠密光流（Dense Optical Flow）作为面向目标场景的 Flow 运动计划； 最后从目标锚点帧（Anchor Frame）出发生成 Target 视频。三个设计支撑了这条动作链： Trace–Flow Motion Planner 把“规划”做成显式的光流预测；Segment-Gapped RoPE（SG-RoPE）在段间插入可学习位置间隔； Trace-Anchored Causal Attention（TACA）保证信息只沿 Trace → Flow → Target 单向流动。

训练数据 X-Act-30K 包含 30,000 对动作匹配视频、覆盖 107 类操作； 在 200 例测试（80 H2H / 80 R2R / 40 H2R）与真实机械臂部署上都取得了领先结果——无需密集推理期标注。

Method 方法

Trace–Flow Motion Planner

把“运动规划”实现为去噪过程中的稠密光流预测：训练时只给 Flow 与 Target 加噪，Flow 以 RAFT 光流为真值，让规划成为显式、可解码的中间环节。

Segment-Gapped RoPE (SG-RoPE)

三段共享一条单调时间轴，段内按像素帧连续编号，段间插入可学习的位置间隔——段与段之间不会被误读成连续物理运动。

Trace-Anchored Causal Attention (TACA)

不对称因果注意力：Trace 只看自身；Flow 不回看 Target；Target 可参考全部。动作理解 → 运动规划 → 画面实现单向流动，条件表示保持稳定。
