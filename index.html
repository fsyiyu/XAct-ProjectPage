01 · 问题

难的不是“会动”，
而是分清“做什么”与“谁来做”。

动作迁移要保留的是动作语义（Action Semantics）：轨迹、接触时机、物体响应； 必须丢掉的是源视频的外观：手形、皮肤、场景纹理。真正的难点是， 现有方法常常直接让源特征流向目标空间，中间没有“先看懂、再规划”的推理环节。

×

外观泄漏
Identity Leakage

从源视频提取的运动特征（时间注意力、频域特征）与演员外观纠缠在一起，注入后生成结果“长得像源演员”，而非目标执行体。

×

刚性复刻
Rigid Replay

依赖逐帧分割掩码或交互轨迹等稠密标注；空间约束是刚性的，无法适应新身体结构、新物体形态下的真实运动。

✓

显式运动规划
Explicit Motion Planner

X-Act 让模型先“读”演示（Trace），再为目标场景“规划”运动（Flow），最后“画出”结果（Target）——三段在同一个去噪过程里完成。

02 · 方法

一条可解码的动作链：
Trace → Flow → Target

三段按时间拼接成一条 token 序列，由一个冻结主干 + 可训练 LoRA 的视频扩散 Transformer 联合去噪； 每一段都可以单独解码查看，让“动作理解、运动规划、画面实现”各司其职。

  1. 01

    Trace · 动作追踪

    参考演示视频的“干净”潜空间编码。它保留完整的时空动作动态与手/夹爪–物体交互，在整个去噪过程中不被噪声污染，是固定的条件。

  2. 02

    Flow · 场景运动规划

    一段稠密光流（Dense Optical Flow）视频，把从 Trace 中读到的动作重新规划为目标场景里应有的位移；它就是这个“Motion Planner”本身。

  3. 03

    Target · 目标视频生成

    从目标场景的锚点帧（Anchor Frame）出发，在 Trace 与 Flow 的共同引导下生成目标视频：动作是它的，样子是“你”的。

A

Trace–Flow Motion Planner

把“规划”实现为去噪过程中的稠密光流预测：训练时只给 Flow 与 Target 加噪并监督，Flow 用 RAFT 光流作为真值，最终无需辅助条件网络。

B

SG-RoPE

Segment-Gapped RoPE：三段共享一条单调时间轴，段间插入可学习位置间隔。段内保持连续运动，段与段之间不会被误读成连续位移。

C

TACA

Trace-Anchored Causal Attention：不对称因果注意力。Trace 只看自身；Flow 不回看 Target；Target 可以参考全部——保证信息单向流动。
